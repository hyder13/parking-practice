# 天下布武 TENKA FUBU 3D

日本戰國(織田信長)主題的 3D 手機射擊(地面縱向捲軸)。由 動物大亂鬥 換皮而來,玩法骨架沿用
(敵軍編隊 → 衝鋒 → 關底大名、30 戰、鐵砲火力 / 官位 / 連擊 / 一閃閃避),引擎是共用的 `../arcade-core`。
主角是 Q 版大頭的織田信長,拿著火繩槍(鐵砲)一路打到天下統一。全部程序生成,沒有圖檔 / 音檔。

## 執行
```
npm install
npm run dev      # http://localhost:5189
npm run build    # → dist/
```

## 操作
- 手機:手指**拖曳**移動,**按著**自動開鐵砲;**另一指點一下**或按右下**一閃**鈕 = 閃身躲開
- 鍵盤:方向鍵 / WASD 移動,SPACE / Z 發射,**X / SHIFT 一閃**,P 暫停,M 靜音

## 內容
| 項目 | 內容 |
|---|---|
| 戰場 | 兩色草地 shader + 蜿蜒的小路 + 河(川中島是很寬的河) |
| 地上 | 陣幕(白布 + 黑帶 + 家紋)+ 各家的のぼり旗(織田 / 武田 / 上杉 / 今川 / 德川 / 毛利 / 明智 / 淺井)、長篠的馬防柵、天守閣(石垣 + 三層白牆 + 金鯱)、寺 + 石燈籠、燃燒的殘骸、櫻 / 松 |
| 7 個戰場 | 尾張、桶狹間(雨)、長篠、川中島(霧)、安土城、比叡山(火)、本能寺(夜火)(stages.js `STAGE_THEME`) |
| 敵軍 | 足輕(陣笠 + 長槍)、忍者(飛身撲過來)、武將(赤備 + 鍬形頭盔,打兩下,被打一下鎧甲變銅色);障礙物是滾過來的焙烙玉;敵彈是手裏劍 |
| 大名 | 武田信玄(諏訪法性兜 + 軍配 +「風林火山」)、上杉謙信(白頭巾 +「毘」)、明智光秀(桔梗紋 + 一圈火 +「敵在本能寺」);獎勵關是千兩箱 |
| 官位(10 段) | 吉法師 → 尾張的傻瓜(紅披風)→ 上總介(大袖)→ 尾張守(刀)→ 天下布武(木瓜紋)→ 岐阜城主(南蠻帽)→ 右大臣(金邊)→ 安土城主(魔王的鬥氣)→ 第六天魔王(金前立頭盔)→ 天下人(火焰光輪) |
| 印籠(道具) | P 鐵砲 / R 疾風 / S 南蠻鎧(護盾)/ B 焙烙玉(清彈幕)/ W 秀吉參上(並肩作戰)/ 1UP 飯糰 |
| 音效 | 法螺貝、陣太鼓、鐵砲「砰」、一閃的刀聲、陣鐘(全部 WebAudio 合成,原創旋律) |
