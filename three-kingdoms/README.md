# 三國英雄 THREE KINGDOMS 3D

三國演義主題的 3D 手機射擊(地面縱向捲軸)。由 齊天大聖 MONKEY KING 換皮而來,玩法骨架沿用
(敵陣 → 衝鋒 → 關底敵將、30 回、武力 / 官階 / 連斬 / 躍馬閃避)。
畫面換成俯視的三國戰場,主角是騎白馬的常山趙子龍。
風格:Q 版大頭 + 紙藝 / 黏土感的「立體繪本」,沿用停車練習場的 cel 陰影 + 深度描線 + 宣紙紋理。
全部程序生成,沒有圖檔 / 音檔(旗子上的字是 canvas 即時畫的)。

## 執行
```
npm install
npm run dev      # http://localhost:5184
npm run build    # → dist/
```

## 操作
- 手機:手指**拖曳**移動,**按著**自動出槍;**另一指點一下**或按右下**躍馬**鈕 = 躍馬閃避(的盧躍檀溪)
- 鍵盤:方向鍵 / WASD 移動,SPACE / Z 出槍,**X / SHIFT 躍馬**,P 暫停,M 靜音

## 立體繪本的手法(參考「三國志 3D 立體繪本」提示詞學來的)
| 手法 | 做法 |
|---|---|
| Q 版大頭比例 | `chibi()`:頭大身小、臉朝鏡頭、整個人偶往後仰(LEAN),俯視也看得到臉 |
| 立體書人偶 | 人物不跟著前進方向轉(`upright`),只左右微傾;每個角色腳下有地面陰影 |
| 從紙面彈起 | 樹 / 營帳 / 石頭捲進畫面時 scale.z 0 → 1 彈性動畫(sea.js `pop`);錦囊掉落時也彈出來 |
| Q 彈回饋 | `squash()`:敵兵到位、被打中、吃道具、敵將落地都會壓扁再彈回 |
| 紙片退場 | 敵將被打敗時被壓扁成紙片、往後倒下 |
| 鏡頭配合節奏 | 敵將落地時畫面震一下 + 重擊音效 |

## 內容

|---|---|
| 戰場 | 草地 shader(兩色色塊 + 小草點 / 野花 + 蜿蜒黃土路,赤壁 / 南蠻多一條江)+ 樹、軍營(帳篷 + 魏 / 吳 / 蜀 / 黃 陣營旗 + 營火)、石頭、落花 / 火星、塵煙 |

| 敵兵 | 黃巾兵(黃頭巾、短槍木盾)、魏軍弓兵(黑盔藍甲)、騎兵(打兩下,盔甲裂開變銅色);敵彈是火箭 |
| 敵將 | 呂布 + 赤兔(雉雞翎、方天畫戟)、曹軍樓船(三層樓閣、藍帆、長槳)、孟獲象兵(長牙、象轎);獎勵關是草船借箭 |
| 官階(10 段) | 小兵 → 伍長 → 什長(龍膽亮銀槍、白馬)→ 百夫長(銀甲)→ 校尉(紅纓、馬鎧)→ 偏將軍(白披風)→ 將軍(四面靠旗)→ 大將軍(金邊)→ 五虎上將(槍身發光)→ 常勝將軍(金光環) |

| 音效 | 銅鑼、戰鼓、五聲音階出陣曲、馬嘶 + 馬蹄(躍馬)、敵將落地重擊(全部 WebAudio 合成) |
