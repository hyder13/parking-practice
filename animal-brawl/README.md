# 動物大亂鬥 ANIMAL BRAWL 3D

卡通動物主題的 3D 手機射擊(地面縱向捲軸)。由 三國英雄 換皮而來,玩法骨架沿用
(動物編隊 → 衝過來 → 關底猛獸、30 回合、骨頭火力 / 等級 / 連擊 / 翻滾閃避),引擎是共用的 `../arcade-core`。
主角是 Q 版大頭的小柴犬,一路丟骨頭,從草原打到冰原。全部程序生成,沒有圖檔 / 音檔。

## 執行
```
npm install
npm run dev      # http://localhost:5188
npm run build    # → dist/
```

## 操作
- 手機:手指**拖曳**移動,**按著**自動丟骨頭;**另一指點一下**或按右下**翻滾**鈕 = 翻滾閃避
- 鍵盤:方向鍵 / WASD 移動,SPACE / Z 發射,**X / SHIFT 翻滾**,P 暫停,M 靜音

## 內容
| 項目 | 內容 |
|---|---|
| 野外 | 兩色草地 / 沙地 / 雪地 shader + 蜿蜒的小路 + 河(海灘是很寬的海) |
| 地上 | 圓樹 / 椰子樹 / 金合歡 / 松 / 仙人掌(依場景)、紅穀倉 + 乾草堆、柵欄 + 指路牌、紅底白點大蘑菇、冰屋、蟻丘、草屋、海灘陽傘 + 毛巾、石頭 |
| 7 種場景 | 草原、叢林、農場、冰原、沙漠、森林、海灘(stages.js `STAGE_THEME`) |
| 小動物 | 兔子(抱紅蘿蔔,一蹦一蹦)、鸚鵡(會拍翅膀)、野豬(打兩下,被打一下氣到發紅);障礙物是滾過來的刺蝟球;敵彈是橡實 |
| 猛獸 | 獅子王(戴金冠)、大鱷魚(張著滿口牙的大嘴)、大猩猩(一圈香蕉繞著轉);獎勵關是黃金倉鼠 |
| 等級(10 段) | 小柴 → 柴柴(紅領巾)→ 勇敢柴(骨頭)→ 探險柴(護目鏡)→ 超級柴(披風)→ 鋼鐵柴(肩甲)→ 酷炫柴(墨鏡)→ 火箭柴(火箭鞋)→ 柴犬國王(皇冠)→ 傳說神柴(光圈) |
| 寵物罐頭(道具) | P 骨頭 / R 快腿 / S 保護泡泡(護盾)/ B 大聲吠(清彈幕)/ W 三花貓助陣 / 1UP 大雞腿 |
| 音效 | 汪!、木琴 + 叢林鼓、鳥叫、猛獸的吼聲、翻滾的彈簧聲(全部 WebAudio 合成,原創旋律) |
