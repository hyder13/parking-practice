# 毛線小世界 YARN LAND

毛線娃娃 / 布偶世界的 3D 手機射擊(地面縱向捲軸)。引擎是共用的 `../arcade-core`,玩法骨架跟其他換皮一樣
(敵人編隊 → 衝過來 → 大魔王、30 段、毛線球火力 / 蓬鬆度進化 / 連擊 / 跳起來閃避)。
主角是橘色毛線頭髮、鈕扣眼睛的毛線娃娃「小毛」,在格子布、牛仔布、毛氈、拼布和針織雪地上,
對抗專吃毛線的飛蛾、襪子怪和剪刀螃蟹。所有東西都帶針織紋、描線是同色的深毛線。全部程序生成,沒有圖檔 / 音檔。

## 執行
```
npm install
npm run dev      # http://localhost:5193
npm run build    # → dist/
```

## 操作
- 手機:手指**拖曳**移動,**按著**自動丟毛線球;**另一指點一下**或按右下**跳**鈕 = 跳起來躲開
- 鍵盤:方向鍵 / WASD 移動,SPACE / Z 發射,**X / SHIFT 跳**,P 暫停,M 靜音
- 標題畫面「布紋」鈕:關掉布紋和畫面四周的縫線框

## 內容
| 項目 | 內容 |
|---|---|
| 畫風 | 每個材質疊上 V 字形的針織紋(src/core/palette.js `TOON`:物件座標 × 物件縮放 + 三平面,針目黏在物件上、大小一致);描線是深一點的同色毛線、毛毛的(`LOOK.inkHooks`);最後一道 shader(`LOOK.style`)= 淡淡的布紋 + 柔光 + 四周的虛線縫邊 |
| 地面 | 野餐格子布、牛仔布(斜紋 + 橘色車縫線)、毛氈、拼布(每格不同花色 + 縫線)、針織、絲絨(亮片)、針線盒的木板 + 捲尺;平針縫的小路、緞帶河 |
| 地上 | 毛球樹 / 毛氈圓樹 / 毛氈松 / 毛氈香菇、大鈕扣、線軸、番茄針插、毛線球 + 棒針、毛氈小屋、頂針、織到一半的圍巾 |
| 7 個場景 | 野餐格子布、牛仔布田野、毛氈森林、拼布小鎮、針織雪地、絲絨夜空、針線盒 |
| 敵人 | 襪子怪(條紋襪子,腳尖是頭)、小飛蛾(毛茸茸 + 四片翅膀,飛在半空)、剪刀螃蟹(兩隻剪刀鉗,打兩下,被打一下殼變紅);障礙物是像輪子一樣滾來的大鈕扣;敵彈是大頭針 |
| 大魔王 | 縫紉機怪(老式縫紉機 + 生氣的臉)、飛蛾女王(王冠 + 四片大翅膀)、毛線團怪(亂成一團的三色毛線 + 一圈棒針);獎勵關是金鈕扣 |
| 蓬鬆度(10 段) | 新手娃娃 → 小毛球(條紋圍巾)→ 毛線學徒(毛球帽)→ 針織好手(連指手套)→ 鈕扣小騎士(大鈕扣)→ 拼布英雄(鉤針小花)→ 刺繡大師(拼布披風)→ 羊毛勇者(棉花光)→ 絨毛之星(鈕扣王冠)→ 毛線之王(毛線球光環) |
| 刺繡徽章(道具) | P 毛線球 / R 快快織 / S 棉花護盾 / B 大毛球(清彈幕)/ W 泰迪熊(並肩作戰)/ 1UP 甜甜圈 |
| 音效 | 軟軟的「噗」、音樂盒、軟木塞「啵」、玩具鼓、玩具喇叭、剪刀「喀嚓」;開場是原創的搖籃曲風小曲 |
