# STAR BEES 星際小蜜蜂 3D

懷舊「小蜜蜂」街機射擊的 3D 化手機版。沿用停車練習場的卡通渲染(cel 陰影 + 深度描線 + 調色),
但保留街機的純黑太空、彩色閃爍像素星、點陣字 HUD 與點陣小圖示。全部程序生成,沒有圖檔 / 音檔。

線上玩:https://hyder13.github.io/parking-practice/star-bees/

## 執行
```
npm install
npm run dev      # http://localhost:5181 (手機同網段可連 Network 位址)
npm run build    # → dist/
```
網址加 `?touch=1` 可在桌機強制觸控模式。

## 操作
- 手機:手指左右**拖曳**移動(相對移動,手指不會擋住戰機),**按著**自動連射
- 鍵盤:← → / A D 移動,SPACE / Z 射擊,P 暫停,M 靜音
- 畫面上最多同時 2 輪子彈(原作規則)

## 五個測試關卡
| 關 | 內容 |
|---|---|
| 1 | 標準進場 5 波 × 8 隻,全部進場後才開始俯衝,敵彈 1 發 |
| 2 | 進場軌跡改成繞圈 / 側切,進場中會開火,同時 3 隻俯衝 |
| 3★ | **獎勵關**:敵人不開火,只照花式軌跡飛過;打中幾隻 × 100,全滅 PERFECT 10000 |
| 4 | 螺旋進場、第 4 波就開始俯衝,蜂會在下方繞圈回頭 |
| 5 | 之字形進場、同時 5 隻俯衝、每次 3 發敵彈 |

第 6 關起五關一輪循環,每輪加速。標題畫面可直接選關測試。

## 經典機制
- 陣型:進場時左右擺動,到齊後「呼吸」一脹一縮;外側的敵人比較容易脫隊俯衝
- 王(橘色)要打兩發,第一發變紫色;帶護衛俯衝時先打掉護衛再打王 = 800 / 1600
- **牽引光束**:王會下來放光束把戰機吸走(變紅色掛在王身後);
  在王攻擊時把它打下來 → 救回變**雙機**(火力加倍、目標也變大);在陣型中打下來 → 戰機逃走
- 20000 / 70000 分加一台,之後每 70000
- GAME OVER 顯示射擊數、命中數、命中率(原作的結算畫面)
