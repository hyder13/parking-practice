# 漫畫英雄 POW! COMIC HERO

美式彩色漫畫(pop art)風格的 3D 手機射擊(地面縱向捲軸)。引擎是共用的 `../arcade-core`,玩法骨架跟其他換皮一樣
(敵人編隊 → 衝過來 → 大魔頭、30 話、能量火力 / 英雄等級 / 連擊 / 飛起來閃避)。
主角是戴黑眼罩、胸前有閃電徽章的 Q 版超級英雄「驚奇小子」,在俯視的漫畫城市裡對抗機器人和大魔頭。
陰影是一顆顆的網點、線條很粗、打爆敵人會跳出 POW! BAM! ZAP!,整個畫面像印在新聞紙上。全部程序生成,沒有圖檔 / 音檔。

## 執行
```
npm install
npm run dev      # http://localhost:5191
npm run build    # → dist/
```

## 操作
- 手機:手指**拖曳**移動,**按著**自動發射能量;**另一指點一下**或按右下**飛**鈕 = 飛起來躲開
- 鍵盤:方向鍵 / WASD 移動,SPACE / Z 發射,**X / SHIFT 飛**,P 暫停,M 靜音
- 標題畫面「印刷感」鈕:關掉新聞紙和套色偏移(網點和黑框保留)

## 內容
| 項目 | 內容 |
|---|---|
| 畫風 | 陰影 = 45° 斜排的網點(src/core/palette.js `TOON`,越暗點越大);最後一道 shader(src/skin.js `LOOK.style`)= 新聞紙 + 套色偏移 + 漫畫格黑框;描線加粗;爆炸跳出狀聲詞(`FEEL.boomWord`) |
| 地面 | 城市街道格子(柏油路 + 黃色虛線 + 斑馬線 + 各色大樓屋頂)、碼頭的水、公園草地、秘密基地的鋼板 + 警示斜紋、火山的熔岩裂縫,全部帶網點 |
| 地上 | 大樓屋頂(水塔 + 冷氣機)、漫畫看板(POW COLA / HERO NEWS…)、卡通小車、貨櫃、港口吊車、化學儲槽、英雄雕像噴泉、能量塔、熔岩石 |
| 7 個場景 | 市中心、港口碼頭、化學工廠、霓虹夜城、中央公園、秘密基地、火山要塞 |
| 敵人 | 機器人小兵(紅色眼罩燈)、噴射背包打手(飛在半空)、大塊頭打手(條紋搶匪衫,打兩下,被打一下氣到臉發紅);障礙物是滾來的油桶;敵彈是洋紅色能量彈 |
| 大魔頭 | 巨型機器人(一圈飛彈)、外星巨腦(玻璃罩 + 飛碟 + 觸手)、大怪獸(背刺 + 尾巴);獎勵關是運鈔車 |
| 英雄等級(10 段) | 新手英雄 → 見習英雄(披風)→ 街頭英雄(腰帶)→ 城市守護者(靴口)→ 超級英雄(徽章白圈)→ 正義隊長(肩甲)→ 傳奇英雄(頭側小翅膀)→ 宇宙英雄(能量光)→ 無敵英雄(金邊)→ 究極英雄(星星光環) |
| 英雄徽章(道具) | P 能量 / R 超音速 / S 力場護盾 / B 大爆炸(清彈幕)/ W 超級狗狗(戴紅眼罩的白狗並肩作戰)/ 1UP 漢堡 |
| 音效 | 能量「咻」、英雄號角(銅管和弦)、定音鼓、城市警報;開場是原創的英雄進行曲 |
