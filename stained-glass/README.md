# 彩窗騎士 STAINED GLASS KNIGHT

教堂彩繪玻璃風格的童話騎士 3D 手機射擊(地面縱向捲軸)。引擎是共用的 `../arcade-core`,玩法骨架跟其他換皮一樣
(敵人編隊 → 衝過來 → 大魔物、30 章、聖光火力 / 騎士階級 / 連擊 / 舉盾閃避)。
主角是拿著光之劍和盾的 Q 版小騎士,整片地面是一幅由一塊塊寶石色玻璃拼成的彩繪玻璃,
每一塊之間是黑色鉛條,角色也像透光的玻璃一樣中間亮、邊緣深。全部程序生成,沒有圖檔 / 音檔。

## 執行
```
npm install
npm run dev      # http://localhost:5194
npm run build    # → dist/
```

## 操作
- 手機:手指**拖曳**移動,**按著**自動發射聖光;**另一指點一下**或按右下**盾**鈕 = 舉盾躍起閃避
- 鍵盤:方向鍵 / WASD 移動,SPACE / Z 發射,**X / SHIFT 舉盾**,P 暫停,M 靜音
- 標題畫面「光束」鈕:關掉斜斜的光束和四周的玻璃窗框(光暈保留)

## 內容
| 項目 | 內容 |
|---|---|
| 畫風 | 地面 = 世界座標的 Voronoi 玻璃碎片 + 鉛條(src/game/sea.js `SEA_FS`);角色 = 透光玻璃材質(src/core/palette.js `TOON`:平面著色的每一面是一片玻璃,正對鏡頭最亮);描線加粗成鉛條;最後一道 shader(src/skin.js `LOOK.style`)= 光暈 + 移動的光束 + 四周一圈彩色小玻璃的窗框 |
| 地面 | 依大區塊混出草地 / 天空 / 花的圖案,偶爾一塊閃亮的花;金色玻璃小路、藍色玻璃河 |
| 地上 | 玫瑰叢 / 棒棒糖樹 / 松、城堡塔(紅藍尖頂 + 小旗)、小教堂(尖拱窗 + 圓花窗)、噴泉、村屋(木骨架)、水晶簇、城門(鐵柵)、暗黑祭壇(紫色魔火) |
| 7 個場景 | 城堡花園、魔法森林、童話村莊、大教堂、湖畔、龍之山谷、暗黑王城 |
| 敵人 | 哥布林(尖耳朵 + 匕首)、蝙蝠(紅眼 + 扇形翅膀,飛在半空)、黑騎士(T 字面甲裡的紅光,打兩下,被打一下盔甲裂開);障礙物是滾來的火球;敵彈是紫紅色魔法彈 |
| 大魔物 | 石巨人(發光符文 + 水晶核心)、紅龍(兩片大翅膀 + 一圈火球)、女巫(尖帽 + 水晶法杖 + 一圈魔藥瓶);獎勵關是聖杯 |
| 騎士階級(10 段) | 見習侍從 → 小侍從(紅羽飾)→ 見習騎士(藍披風)→ 騎士(盾上的金菱紋)→ 聖騎士(金邊)→ 圓桌騎士(肩甲)→ 皇家騎士(白翅膀頭盔)→ 光之騎士(聖光)→ 傳說騎士(王冠)→ 聖光王者(玫瑰花窗光環) |
| 寶石(道具) | P 聖光 / R 疾光 / S 聖盾(護盾)/ B 光之爆(清彈幕)/ W 獨角獸(並肩作戰)/ 1UP 蘋果派 |
| 音效 | 聖光「叮」、教堂鐘聲、管風琴和弦、魯特琴撥弦、號角;開場是原創的中世紀風小曲 |
