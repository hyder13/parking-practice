# 夜市美食大戰 NIGHT MARKET 3D

台灣夜市主題的 3D 手機射擊(地面縱向捲軸)。由 鬧熱廟會 換皮而來,玩法骨架沿用
(小吃編隊 → 衝過來 → 關底招牌料理、30 攤、加料 / 吃貨等級 / 連擊 / 借過閃避),引擎是共用的 `../arcade-core`。
主角是 Q 版大頭的小吃貨,手上拿著珍珠奶茶發射珍珠,一攤一攤吃過去。全部程序生成,沒有圖檔 / 音檔。

## 執行
```
npm install
npm run dev      # http://localhost:5187
npm run build    # → dist/
```

## 操作
- 手機:手指**拖曳**移動,**按著**自動發射珍珠;**另一指點一下**或按右下**借過**鈕 = 跳起來閃避
- 鍵盤:方向鍵 / WASD 移動,SPACE / Z 發射,**X / SHIFT 借過**,P 暫停,M 靜音

## 內容
| 項目 | 內容 |
|---|---|
| 夜市走道 | 地磚 shader(散落彩色紙屑;雨夜有水窪和兩側霓虹招牌拉長的彩色倒影)+ 騎樓;兩側是屋頂群 / 河濱的河水 |
| 街景 | 店屋 + 發光的霓虹招牌(珍奶 / 雞排 / 牛排 / 當舖 / KTV…)、小吃攤(條紋遮雨棚 + 招牌:臭豆腐 / 大腸包小腸 / 珍珠奶茶 / 蚵仔煎 / 章魚燒…,攤上有鍋子 / 烤架 / 飲料 / 炸物)、射氣球、撈金魚、廟口的廟、彩色燈泡串 / 紅燈籠、攤子冒出來的蒸氣 |
| 7 種場景 | 小吃街、霓虹街、遊戲區、廟口、河濱、雨夜、過年夜市(stages.js `STAGE_THEME`) |
| 小吃 | 臭豆腐(上面一坨泡菜 + 綠色臭氣,一蹦一蹦)、雞排(比臉大,插在紙袋裡飛)、刈包(打兩下,被打一下氣到發紅);障礙物是貢丸串;敵彈是辣椒 |
| 招牌料理 | 大腸包小腸、蚵仔煎(盤子旁繞著一圈蚵仔)、麻辣鍋(鍋外繞著一圈辣椒);獎勵關是棉花糖 |
| 吃貨等級(10 段) | 小吃貨(珍奶)→ 攤販學徒(毛巾頭巾)→ 小老闆(圍裙)→ 鐵板燒手(鍋鏟)→ 大廚(廚師帽)→ 夜市達人(雙手珍奶)→ 米其林(星星)→ 美食評審(金杯 + 金帽)→ 夜市傳奇(金項鍊)→ 夜市之王(皇冠 + 光圈) |
| 手搖杯(道具) | P 加料 / R 手速 / S 保溫袋(護盾)/ B 爆米香(清彈幕)/ W 外送員(並肩作戰)/ 1UP 雞蛋糕 |
| 音效 | 發射珍珠「啵」、借過的機車喇叭「叭叭」、鐵板「滋——」、收銀機「叮鈴」、攤販搖鈴、爆米香「碰」(全部 WebAudio 合成,原創旋律) |
