# 蒸汽天空 STEAM SKY

蒸汽龐克風格的小飛行員 3D 手機射擊(地面縱向捲軸)。引擎是共用的 `../arcade-core`,玩法骨架跟其他換皮一樣
(敵人編隊 → 衝過來 → 巨大機械、30 航段、火力 / 飛行員階級 / 連擊 / 蒸汽噴射閃避)。
主角是戴黃銅護目鏡、背著蒸汽背包的 Q 版小飛行員,底下是俯視的維多利亞城市:一格格的屋頂、石板街、煤氣路燈、
冒煙的工廠、鐵軌和運河。黃銅零件會反光,整個畫面偏琥珀色,一團團蒸汽飄過去。全部程序生成,沒有圖檔 / 音檔。

## 執行
```
npm install
npm run dev      # http://localhost:5195
npm run build    # → dist/
```

## 操作
- 手機:手指**拖曳**移動,**按著**自動發射鉚釘;**另一指點一下**或按右下**噴**鈕 = 蒸汽噴射閃避
- 鍵盤:方向鍵 / WASD 移動,SPACE / Z 發射,**X / SHIFT 噴射**,P 暫停,M 靜音
- 標題畫面「蒸汽」鈕:關掉飄過的蒸汽和四周的黃銅框(琥珀色保留)

## 內容
| 項目 | 內容 |
|---|---|
| 畫風 | 暖色零件 = 拋光黃銅(src/core/palette.js `TOON`:明暗對比大 + 環境反光 + 亮點);描線是深棕色;最後一道 shader(src/skin.js `LOOK.style`)= 琥珀色調 + 泛光 + 蒸汽 + 黃銅鉚釘框 |
| 地面 | 城市街區(石板 / 紅磚瓦 / 綠銅屋頂、煙囪口、天窗、路口的煤氣燈、房子的影子)、郊外荒地、鐵軌、紅磚岸的運河 |
| 地上 | 公園樹 / 煤氣路燈 / 蒸汽管、工廠(大煙囪冒煙)、鐘樓、儲氣槽、蒸汽幫浦(飛輪會轉)、起重機、水塔、鐵要塞 |
| 7 個場景 | 煙囪城、鐘樓廣場、運河碼頭、煤礦山谷、鐵道平原、雲上工廠、風暴要塞 |
| 敵人 | 發條兵(高軍帽 + 背上的發條鑰匙)、發條蜻蜓(玻璃大眼 + 四片翅膀,飛在半空)、蒸汽機器人(舷窗臉 + 煙囪,打兩下);障礙物是滾來的大齒輪;敵彈是燒紅的煤球 |
| 巨大機械 | 機械巨鯨(舷窗 + 胸鰭 + 一圈螺旋槳)、鐘樓巨人(大鐘面 + 一圈齒輪)、海盜飛艇(骷髏徽章 + 黑帆 + 一圈炸彈);獎勵關是黃金懷錶 |
| 飛行員階級(10 段) | 見習飛行員 → 學徒(紅圍巾)→ 三等(蒸汽背包)→ 二等(黃銅肩甲)→ 一等(壓力錶 + 金腰帶)→ 王牌(螺旋槳)→ 隊長(紅銅小翅膀)→ 艦長(蒸汽光暈)→ 傳說艦長(金齒輪)→ 天空之王(大齒輪光環) |
| 齒輪幣(道具) | P 火力 / R 連發 / S 護盾 / B 蒸汽炸彈(清彈幕)/ W 機械貓頭鷹(並肩作戰)/ 1UP 紅茶 |
| 音效 | 鉚釘「叮」、蒸汽嘶聲、汽笛、汽笛風琴、大號、金屬撞擊;開場是原創的圓舞曲風小曲 |
