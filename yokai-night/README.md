# 百鬼夜行 HYAKKI YAGYO 3D

浮世繪風格的日本妖怪 3D 手機射擊(地面縱向捲軸)。由 鬧熱廟會 換皮而來,玩法骨架沿用
(妖怪編隊 → 衝過來 → 關底大妖怪、30 夜、靈力 / 位階 / 連擊 / 飛躍閃避),引擎是共用的 `../arcade-core`。
主角是 Q 版的少年陰陽師(黑烏帽子 + 淡藍狩衣),在平安京的夜路上擲符除妖。
畫面走浮世繪木版畫的路線:平塗色塊(cel 只分 2 階)、粗墨線、普魯士藍 / 朱紅 / 米色和紙、金色的霞雲帶。
全部程序生成,沒有圖檔 / 音檔。

## 執行
```
npm install
npm run dev      # http://localhost:5186
npm run build    # → dist/
```

## 操作
- 手機:手指**拖曳**移動,**按著**自動擲符;**另一指點一下**或按右下**飛躍**鈕 = 飛躍閃避
- 鍵盤:方向鍵 / WASD 移動,SPACE / Z 發射,**X / SHIFT 飛躍**,P 暫停,M 靜音

| 7 種場景 | 平安京、千本鳥居、竹林、夜櫻、浪裏(北斎)、雪夜、紅葉(stages.js `STAGE_THEME`) |
| 妖怪 | 唐傘妖(大獨眼 + 長舌,單腳跳)、提燈妖(裂開的燈籠,飄在半空)、赤鬼(雙角 + 金棒,打兩下,被打一下變青鬼);障礙物是燃燒的輪入道;敵彈是人魂 |
| 大妖怪 | 雷神(背後一圈轉動的三つ巴太鼓)、九尾狐(九條尾巴像扇子張開、會擺)、がしゃどくろ(從地面爬出來的巨大骷髏);獎勵關是招財貓 |

| 繪馬(道具) | P 靈力 / R 疾風 / S 結界(護盾)/ B 爆符(清彈幕)/ W 式神白狐(並肩作戰)/ 1UP 三色糰子 |
| 音效 | 歌舞伎的拍子木(越打越快)、三味線(都節音階)、太鼓、梵鐘、擲符的紙聲(全部 WebAudio 合成,原創旋律) |
