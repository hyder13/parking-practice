# 黑白卡通劇場 CARTOON REEL 1930

1930 年代黑白卡通風格的 3D 手機射擊(地面縱向捲軸)。引擎是共用的 `../arcade-core`,玩法骨架跟其他換皮一樣
(敵人編隊 → 衝過來 → 大反派、30 集、喇叭火力 / 星途進化 / 連擊 / 蹦!閃避)。
主角是橡皮管手腳、派切眼、戴白手套的卡通小狗「小咚」,吹小喇叭射音符。
整個畫面會轉成泛黃的黑白底片,加上顆粒、刮痕、閃爍和放映機暗角。全部程序生成,沒有圖檔 / 音檔。

## 執行
```
npm install
npm run dev      # http://localhost:5190
npm run build    # → dist/
```

## 操作
- 手機:手指**拖曳**移動,**按著**自動吹喇叭;**另一指點一下**或按右下**蹦**鈕 = 彈起來躲開
- 鍵盤:方向鍵 / WASD 移動,SPACE / Z 發射,**X / SHIFT 蹦**,P 暫停,M 靜音
- 標題畫面「老膠卷」鈕:關掉顆粒 / 刮痕 / 閃爍(黑白和暗角保留)

## 內容
| 項目 | 內容 |
|---|---|
| 畫風 | 最後一道 shader(src/skin.js `LOOK.style`)把畫面轉成泛黃黑白 + 高對比 + 顆粒 + 垂直刮痕 + 灰塵斑點 + 片子晃動 + 圓角片框;描線每 1/12 秒重抖一次(`LOOK.inkHooks`),像手繪動畫一格一格重描 |
| 地面 | 水彩背景的斑駁灰階 + 小路(小鎮是石板街)、港口的河(一段一段的水波紋)、夢境的雲海 |
| 地上 | 有臉的圓樹、枯樹、窗戶是眼睛的小屋、穀倉、乾草堆、馬戲團帳篷、RIP 墓碑、碼頭小船 —— 全部跟著拍子一起蹦 |
| 7 個場景 | 小鎮大街、快樂農場、午夜墓園、碼頭港口、馬戲團、雲上夢境、月夜狂歡 |
| 敵人 | 跳舞的花(白花瓣笑臉 + 葉子手)、小幽靈(白床單,飄在半空)、骷髏(打兩下,被打一下骨頭變暗);障礙物是有怒眼的滾動炸彈;敵彈是奶油派 |
| 大反派 | 火車頭老大(八字鬍 + 一圈蒸汽)、月亮先生(睡帽 + 一圈星星)、大野狼(高禮帽 + 拐杖);獎勵關是錢袋先生 |
| 星途(10 段) | 臨時演員 → 跑龍套(領結)→ 小配角(白襯衫)→ 配角(草帽)→ 男主角(星星)→ 當家小生(拐杖)→ 大明星(高禮帽)→ 超級巨星(聚光燈)→ 影壇傳奇(鞋套 + 胸花)→ 卡通之王(音符光環) |
| 黑膠唱片(道具) | P 喇叭 / R 快板 / S 泡泡糖(護盾)/ B 大炸彈(清彈幕)/ W 小鋼琴(會走路的鋼琴並肩作戰)/ 1UP 熱狗 |
| 音效 | 小喇叭、滑哨、彈簧「啵嚶」、木琴、大號、大鈸、火車汽笛;開場是原創的拉格泰姆 |
