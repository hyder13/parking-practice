# 齊天大聖 MONKEY KING 3D

西遊記主題的 3D 手機射擊。由 SKY ACES 1945(再往前是 STAR BEES 星際小蜜蜂 3D)整個換皮而來:
玩法骨架(編隊 → 俯衝 → 關底大妖、30 關、法力 / 修為 / 連擊 / 翻筋斗)沿用,
畫面換成從雲端往下看的水墨仙境,主角是踩著筋斗雲的孫悟空。
沿用停車練習場的卡通渲染(cel 陰影 + 深度描線 + 調色),描線加粗、調色偏宣紙色,做出水墨 / 國畫的感覺。
全部程序生成,沒有圖檔 / 音檔。

## 執行
```
npm install
npm run dev      # http://localhost:5183
npm run build    # → dist/
```
網址加 `?touch=1` 可在桌機強制觸控模式。

## 操作
- 手機:手指**拖曳**移動,**按著**自動發射;**另一指點一下**或按右下**筋斗**鈕 = 翻筋斗
- 鍵盤:方向鍵 / WASD 移動,SPACE / Z 發射,**X / SHIFT 翻筋斗**,P 暫停,M 靜音
- **翻筋斗**:約 1.25 秒無敵(不能發射),每關 3 次
