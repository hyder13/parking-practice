# 鬧熱廟會 TEMPLE FESTIVAL 3D

台灣廟會遶境主題的 3D 手機射擊(地面縱向捲軸)。由 三國英雄 換皮而來,玩法骨架沿用
(鬼怪編隊 → 衝過來 → 關底大魔頭、30 站、神力 / 神格 / 連擊 / 風火輪閃避)。
主角是 Q 版大頭的電音三太子(神將本來就是大頭比例,奶嘴、墨鏡都有),一路遶境驅邪。
風格沿用「立體繪本」手法:紙板人偶、從紙面彈起的街景、Q 彈回饋、紙片退場。全部程序生成,沒有圖檔 / 音檔。

## 執行
```
npm install
npm run dev      # http://localhost:5185
npm run build    # → dist/
```

## 操作
- 手機:手指**拖曳**移動,**按著**自動丟乾坤圈;**另一指點一下**或按右下**風火輪**鈕 = 衝刺閃避
- 鍵盤:方向鍵 / WASD 移動,SPACE / Z 發射,**X / SHIFT 風火輪**,P 暫停,M 靜音

## 內容
| 項目 | 內容 |
|---|---|
| 遶境路線 | 石板 / 紅磚街道 shader(交錯磚縫 + 散落的鞭炮紅紙屑)+ 騎樓人行道;兩側是屋頂群 / 稻田 / 海水 |
| 街景 | 老街店屋(紅瓦 + 直式招牌:香鋪 / 金紙 / 餅店 / 豆花…,字是 canvas 即時畫的)、廟宇(橘紅琉璃瓦 + 燕尾脊 + 剪黏雙龍搶珠 + 香爐)、攤販陽傘、供桌、跨街的一排紅燈籠、鞭炮煙 |
| 7 種場景 | 廟埕、老街、夜市、鞭炮陣、鄉間、漁港、燈會(config.js `STAGE_THEME`) |
| 鬼怪 | 小鬼(獨角、狼牙棒)、殭屍(清朝官帽 + 黃符 + 雙手平舉,一跳一跳)、夜叉(火焰紅髮、三叉戟,打兩下);敵彈是鬼火 |
| 大魔頭 | 年獸(像舞獅的金色鬃毛、獨角)、虎姑婆(虎頭 + 老婆婆衣服 + 髮髻紅花 + 拐杖)、鬼王(綠臉金冠 + 繞身鬼火);獎勵關是大紅包 |
| 神格(10 段) | 小太子 → 童子(乾坤圈)→ 神童(混天綾)→ 小將(火尖槍)→ 將軍(金甲)→ 元帥(風火輪)→ 中壇元帥(墨鏡!)→ 太子爺(LED 螢光棒)→ 電音太子(金冠)→ 神威太子(神光圈) |
| 平安符 | P 神力 / R 疾速 / S 平安符(護盾)/ B 鞭炮(清彈幕)/ W 七爺助陣(並肩作戰)/ 1UP 紅龜粿 |
| 音效 | 鞭炮劈哩啪啦、嗩吶五聲音階、銅鑼、大鼓、乾坤圈「叮」(全部 WebAudio 合成,原創旋律) |
