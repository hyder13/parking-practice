# 小法老 LITTLE PHARAOH

古埃及墓室壁畫風格的小法老 3D 手機射擊(地面縱向捲軸)。引擎是共用的 `../arcade-core`,玩法骨架跟其他換皮一樣
(敵人編隊 → 衝過來 → 守護者、30 關、太陽之力 / 法老階級 / 連擊 / 風沙閃避)。
主角是戴藍金條紋頭巾的 Q 版小法老,底下是沙丘、尼羅河(壁畫畫水的鋸齒紋)、紙莎草、田和石板神殿大道。
整個畫面只用幾種礦物顏料的平塗 + 粗黑線,疊上莎草紙的纖維,四周一圈壁畫邊框。全部程序生成,沒有圖檔 / 音檔。

## 執行
```
npm install
npm run dev      # http://localhost:5196
npm run build    # → dist/
```

## 操作
- 手機:手指**拖曳**移動,**按著**自動發射太陽光;**另一指點一下**或按右下**沙**鈕 = 捲起風沙閃避
- 鍵盤:方向鍵 / WASD 移動,SPACE / Z 發射,**X / SHIFT 閃避**,P 暫停,M 靜音
- 標題畫面「壁畫」鈕:關掉莎草紙紋和四周的壁畫邊框(顏料色保留)

## 內容
| 項目 | 內容 |
|---|---|
| 畫風 | 材質 = 平塗(src/core/palette.js `TOON`:正面原色、側面深一階);描線粗黑 + 微微手抖;最後一道 shader(src/skin.js `LOOK.style`)= 顏色往礦物顏料靠 + 莎草紙纖維 + 藍紅綠金的壁畫邊框 |
| 地面 | 三個色階的沙丘 + 風紋、尼羅河(黑色鋸齒紋)+ 紙莎草岸 + 一條條的田、石板神殿大道、冥界的金色星星 |
| 地上 | 棕櫚樹 / 紙莎草 / 蓮花柱、金字塔(金色塔尖)、方尖碑、神殿門、小獅身像、帝王谷的墓門、坐像、冥界祭壇 |
| 7 個場景 | 金色沙漠、尼羅河畔、金字塔群、神殿大道、綠洲、帝王谷、冥界 |
| 敵人 | 木乃伊(繃帶縫裡發亮的眼)、聖甲蟲(推著紅太陽,飛在半空)、胡狼守衛(尖耳朵 + 金項圈 + 長矛,打兩下);障礙物是滾來的石球;敵彈是赭紅色的詛咒火球 |
| 守護者 | 人面獅身(一圈生命之符)、巨蛇(張開的頸部 + 一圈鬼火)、巨蠍(大鉗 + 毒針 + 一圈火球);獎勵關是黃金面具 |
| 法老階級(10 段) | 小王子 → 王子(眼鏡蛇)→ 王儲(彩色寬項圈)→ 小法老(彎鉤權杖)→ 上下埃及之王(金臂環)→ 尼羅河之主(披風)→ 荷魯斯之子(翅膀)→ 太陽的化身(光暈)→ 萬王之王(太陽圓盤)→ 太陽之子(帶翅膀的太陽) |
| 護身符(道具) | P 太陽之力 / R 疾風 / S 護身符(護盾)/ B 沙暴(清彈幕)/ W 聖貓(並肩作戰)/ 1UP 椰棗 |
| 音效 | 太陽光「叮」、豎琴、叉鈴、蘆笛、大鼓;開場是原創的異國風小曲 |
