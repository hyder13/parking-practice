# 水墨江湖 INK & SWORD

中國水墨畫風格的武俠 3D 手機射擊(地面縱向捲軸)。引擎是共用的 `../arcade-core`,玩法骨架跟其他換皮一樣
(敵人編隊 → 衝過來 → 強敵、30 回、劍氣火力 / 功力進化 / 連擊 / 輕功閃避)。
主角是白衫紅髮帶的少年劍客,在宣紙上的竹林、客棧、山水、雪山和荷塘之間,一路打到武林盟主。
整個畫面是墨色的濃淡 + 宣紙留白,只有朱紅(印章、紅繩、酒旗、梅花、敵人的飛鏢)是鮮色。全部程序生成,沒有圖檔 / 音檔。

## 執行
```
npm install
npm run dev      # http://localhost:5192
npm run build    # → dist/
```

## 操作
- 手機:手指**拖曳**移動,**按著**自動發出劍氣;**另一指點一下**或按右下**輕功**鈕 = 躍起閃避
- 鍵盤:方向鍵 / WASD 移動,SPACE / Z 發射,**X / SHIFT 輕功**,P 暫停,M 靜音
- 標題畫面「宣紙」鈕:關掉紙紋和墨暈(墨色和朱紅保留)

## 內容
| 項目 | 內容 |
|---|---|
| 畫風 | 最後一道 shader(src/skin.js `LOOK.style`)把畫面換成墨分五色(柔邊的幾層濃淡)+ 宣紙底 + 纖維 + 墨的顆粒 + 墨暈(取樣跟著紙纖維歪),紅色保留成朱砂色、其他顏色只留一點淡彩;描線是毛筆(`LOOK.inkHooks`:提按的粗細 + 飛白) |
| 地面 | 宣紙留白 + 淡墨暈染 + 皴法短筆觸、江(兩岸濃墨 + 水紋)、雪地、荷塘、魔教的濃墨 |
| 地上 | 竹林、松、梅(朱紅花點)、柳、亭子、石拱橋、小舟、客棧(紅燈籠 +「酒」旗)、山石、荷花、石燈籠、魔教祭壇(火盆 + 紅旗)、雲霧(留白) |
| 7 個場景 | 竹林、客棧小鎮、山水、雪山、荷花湖、懸崖古寺、魔教總壇 |
| 敵人 | 山賊(包頭巾 + 絡腮鬍 + 大刀)、飛賊(黑衣蒙面 + 紅圍巾,用輕功飛過來)、鐵頭陀(光頭 + 大念珠 + 鐵禪杖,打兩下,被打一下光頭氣紅);障礙物是滾來的酒罈;敵彈是朱紅飛鏢 |
| 強敵 | 山寨大王(虎皮背心 + 月牙大刀 +「黑風寨」旗)、墨龍(龍頭 + 鹿角 + 龍鬚,龍身繞著牠轉)、魔教教主(白臉紅眼影 + 長髮 + 一圈紅符);獎勵關是武功秘笈 |
| 功力(10 段) | 初出茅廬 → 江湖新秀(紅頭帶)→ 少年俠客(背上斗笠)→ 青衫劍客(第二把劍)→ 名門弟子(墨色外袍)→ 一流高手(酒葫蘆)→ 劍術名家(玉珮 + 長馬尾)→ 一代宗師(墨色真氣)→ 劍聖(戴上斗笠)→ 武林盟主(一圈飛劍) |
| 卷軸(道具) | P 劍氣 / R 快劍 / S 金鐘罩(護盾)/ B 霹靂彈(清彈幕)/ W 仙鶴(白鶴並肩作戰)/ 1UP 包子 |
| 音效 | 劍氣「唰」、琵琶 / 古琴的撥弦、竹笛、大鼓、銅鑼;開場是原創的五聲音階小曲 |
